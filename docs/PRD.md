# FinancePilot AI PRD

## 1. 서비스 아이디어

**FinancePilot AI**는 기업의 재무 데이터를 AI로 분석하여, 사용자가 기업의 **재무 건전성·성장성·과거 추세**를 빠르게 파악할 수 있도록 돕는 AI 기반 기업 분석 웹서비스다.

사용자가 기업명 또는 종목코드를 검색하면 DART의 재무·공시 데이터를 수집하고, 업종 특성과 과거 추세를 고려하여 AI가 분석한 결과를 하나의 Dashboard에서 제공한다.

MVP 이후에는 외부 뉴스 데이터를 추가하여 최신 이슈 분석 기능을 확장하고, 사용자가 분석할 기업을 직접 검색하지 않아도 되도록 **최근 인기 테마 기반 추천 기업**과 **즐겨찾기** 기능을 제공한다.

### 핵심 사용자 경험

```text
[사용자가 기업 검색]
        ↓
     Company ID
        ↓
   기업 분석 Dashboard
        ↓
DART 재무 + 업종 특성 + 과거 추세
        ↓
      AI 분석
        ↓
핵심 강점 / 위험요인 / 재무 상태 / 체크포인트
```

MVP의 핵심 방향:

> **"기업 하나를 검색하면, 재무 상태와 성장성을 빠르게 이해할 수 있게 한다."**

MVP 이후:

> **"기업을 모르는 사용자도 관심이 높은 테마와 추천 기업을 통해 분석을 시작할 수 있게 한다."**

# 2. 대상 사용자

### 핵심 사용자

**개인 투자자**

* 기업의 재무 상태를 분석하는 투자자
* 재무제표를 직접 해석하기 어려운 초보 투자자
* 기업의 과거 실적과 재무 추세를 빠르게 확인하고 싶은 사용자
* 어떤 기업을 분석해야 할지 모르는 사용자

### 핵심 사용자 니즈

* 기업 분석 정보가 여러 곳에 분산되어 있다.
* 재무제표의 숫자만으로 기업 상태를 이해하기 어렵다.
* 동일한 재무지표라도 업종에 따라 의미가 다르다.
* 기업의 현재 재무 상태와 과거 추세를 한눈에 파악하기 어렵다.
* 분석할 기업을 찾는 것 자체가 어렵다.
* 관심 기업을 따로 관리하고 지속적으로 확인하기 어렵다.

---

# 3. 사용자가 겪는 문제

### 문제 1. 기업의 재무 정보가 복잡하다.

매출, 영업이익, 부채비율, ROE 등의 숫자를 확인해도 기업의 실제 재무 상태를 판단하기 어렵다.

### 문제 2. 재무 데이터를 직접 해석하기 어렵다.

재무제표를 확인하더라도 어떤 지표가 중요한지, 수치가 좋은지 나쁜지 판단하기 어렵다.

### 문제 3. 업종별 특성을 고려하기 어렵다.

유동비율, 부채비율, 영업이익률 등의 적정 수준과 해석은 업종의 사업 구조와 자본집약도에 따라 달라질 수 있다.

따라서 모든 업종에 동일한 절대 기준을 적용하는 것은 적절하지 않다.

### 문제 4. 과거 추세를 파악하기 어렵다.

현재의 재무지표만으로는 기업의 재무 상태가 개선되고 있는지 악화되고 있는지 판단하기 어렵다.

### 문제 5. 분석할 기업을 찾기 어렵다.

주식 초보자는 어떤 기업을 검색하고 분석해야 할지 모를 수 있다.

따라서 MVP 이후 최근 시장의 관심이 높아진 테마와 관련 종목을 제공하여 분석의 시작점을 제공한다.

# 4. 제품이 제공할 핵심 가치

## ① 기업 분석 시간 단축

기업명 하나만 검색하면 재무 데이터를 한 화면에서 확인할 수 있도록 한다.

## ② 복잡한 재무 데이터의 AI 해석

AI가 주요 재무지표의 의미와 기업의 재무 상태를 쉽게 설명한다.

## ③ 과거 추세 기반 분석

현재 수치뿐만 아니라 최근 3~5년의 재무 추세를 함께 제공한다.

## ④ 업종 특성을 고려한 분석

재무지표를 단일 절대 기준으로 평가하지 않고 다음을 함께 고려한다.

```text
일반적인 재무 기준
+
업종 특성
+
과거 3~5년 추세
↓
AI 해석
```

## ⑤ 분석할 기업 추천

MVP 이후 사용자가 특정 기업을 모르는 경우에도 최근 시장의 관심이 높은 테마와 관련 종목을 제공하여 분석을 시작할 수 있도록 한다.

## ⑥ 관심 기업 관리

MVP 이후 사용자가 관심 있는 기업을 즐겨찾기에 추가하고 한 곳에서 관리할 수 있도록 한다.

# 5. 주요 기능

## ① 기업 검색

* 기업명 검색
* 종목코드 검색
* 기업 기본정보 제공

검색 결과에서 기업을 선택하면 해당 기업의 `Company ID`를 기준으로 기업 분석 Dashboard로 이동한다.

---

## ② 재무 분석

DART 데이터를 기반으로 주요 재무정보를 제공한다.

### 주요 지표

* 매출
* 영업이익
* 순이익
* 영업현금흐름
* FCF
* ROE
* ROIC
* 영업이익률
* 부채비율
* 유동비율
* 이자보상배율
* 매출·영업이익 성장률

### 제공 방식

각 지표에 대해 가능한 경우:

* 현재 수치
* 최근 3~5년 추세
* 기본적인 재무 상태 평가
* AI 해석

을 제공한다.

---

## ③ 업종 특성 기반 지표 해석

기업의 업종 정보를 기반으로 재무지표를 해석한다.

```text
기업 재무지표
↓
일반적인 재무 기준
+
업종 특성
+
과거 추세
↓
AI 해석
```

업종별 유동비율, 부채비율, 영업이익률 등의 특성과 일반적인 해석 기준은 신뢰할 수 있는 산업·금융 자료를 참고하여 구축한다.

MVP에서는 정교한 업종별 Benchmark 모델을 구축하지 않는다.

단, AI가 모든 업종에 동일한 절대 기준을 적용하지 않도록 업종 특성 참고 데이터를 분석 규칙 또는 AI 프롬프트에 활용한다.

---

## ④ 기업 통합 Dashboard

기업을 검색하면 다음 정보를 하나의 Dashboard에서 제공한다.

```text
기업 기본정보
↓
주요 재무지표
↓
재무 추세
↓
AI 재무 분석
↓
주요 강점
↓
주요 위험요인
↓
투자 체크포인트
```

**검색 진입과 추천 기업 진입은 동일한 분석 페이지와 분석 로직을 사용한다.**

---

## ⑤ AI 종합 재무 분석

DART 재무 데이터와 업종 특성 및 과거 추세를 종합하여 다음을 제공한다.

* 기업 한줄 요약
* 재무 상태 요약
* 주요 강점
* 주요 위험요인
* 성장성 분석
* 최근 재무 추세
* 투자자가 확인할 체크포인트

AI는 투자 결정을 직접 대신하지 않고 투자 판단에 필요한 정보를 구조화하고 해석한다.

### MVP 목표

### 기업

* 기업명 / 종목코드 검색

### 종합 분석

# 7. MVP 이후 추가 기능

## 7-1. 최신 뉴스 분석

MVP에서 제외한 뉴스 기능은 향후 외부 뉴스 데이터 API를 선정한 후 추가한다.

### 주요 기능

* 기업 관련 최신 뉴스 수집
* 실적 관련 뉴스
* 수주 및 공급계약
* 신제품
* M&A
* 목표주가
* 업종별 주요 이벤트
* 뉴스 중복 제거
* AI 뉴스 요약
* 긍정 / 중립 / 부정 분류

### 분석 흐름

```text
기업 검색
↓
Company ID
↓
외부 뉴스 API
↓
기업 관련 뉴스 수집
↓
뉴스 정제 / 중복 제거
↓
OpenAI API
↓
뉴스 요약 및 분석
↓
기업 Dashboard에 표시
```

뉴스 데이터 공급자는 MVP 이후 실제 이용 가능 여부와 API 정책을 확인하여 선정한다.

MVP는 특정 뉴스 API에 의존하지 않는다.

---

## 7-2. 추천 기업

### 목적

기업을 직접 검색할 기업을 모르는 사용자에게 분석 시작점을 제공한다.

### 사용자 흐름

```text
홈 화면
↓
최근 인기 테마
↓
테마별 추천 기업
↓
기업 선택
↓
Company ID
↓
기존 기업 분석 Dashboard
```

### 추천 기준

최근 **1~2주간 시장에서 관심이 증가한 인기 테마**를 우선 선정한다.

인기 테마와 추천 종목은 다음 데이터를 조합하여 산출하는 방향으로 구현한다.

```text
검색 관심도
+
뉴스 모멘텀
+
시장 거래량 변화
+
거래대금
↓
인기 테마 선정
↓
테마 관련 종목 추출
↓
테마 내 거래량 / 거래대금 상위 종목 선정
↓
추천 기업
```

초기 추천 점수는 복잡한 AI 모델보다 단순한 규칙 기반으로 구현할 수 있다.

추천 기업은 단순 거래량만으로 선정하지 않는다.

### 화면 예시

```text
최근 인기 테마

[AI / 반도체]
최근 관심 증가

- 종목 A
- 종목 B
- 종목 C

[방산]
최근 관심 증가

- 종목 D
- 종목 E
- 종목 F
```

추천 기업 클릭 시 기존 기업 분석 Dashboard로 이동한다.

**추천 기업을 위한 별도의 기업 분석 로직을 만들지 않는다.**

# 9. 사용할 데이터 또는 외부 API

## ① DART Open API — MVP 핵심

사용 목적:

* 기업 기본정보
* 재무제표
* 재무 관련 공시
* 기업 공시

### 기업 식별

사용자가 입력한 종목코드와 DART `corp_code`를 Company Master에서 매핑한다.

```text
기업명 / 종목코드
↓
Company Master
↓
corp_code
↓
DART API
```

DART의 `corp_code` 매핑 데이터는 서버 시작 시 로드하거나 DB에 저장하여 사용한다.

---

## ② OpenAI API — MVP 핵심

사용 목적:

* 재무 데이터 해석
* 재무 상태 요약
* 성장성 분석
* 강점 및 위험요인 도출
* 투자 체크포인트 생성
* AI 종합 재무 분석

분석 흐름:

```text
DART 재무 데이터
+
업종 정보
+
과거 재무 추세
↓
OpenAI API
↓
AI 재무 분석
```

AI 분석은 반드시 실제 수집된 데이터에 기반해야 하며, 존재하지 않는 재무 수치나 사실을 생성하지 않는다.

---

## ③ 업종별 지표 특성 참고 데이터 — MVP 보조

별도의 금융 데이터 API를 핵심 의존성으로 사용하지 않는다.

신뢰할 수 있는 산업·금융 자료를 참고하여 다음 내용을 구축한다.

* 업종별 재무지표 특성
* 자본집약도
* 일반적인 부채 구조
* 유동성 특성
* 수익성 수준

이 데이터는 실시간 API가 아니라 FinancePilot AI의 분석 규칙 및 AI 프롬프트를 보완하는 참고 데이터로 활용한다.

---

## ④ 네이버 데이터랩 — MVP 이후 활용 가능

네이버 데이터랩 검색어 트렌드는 기업의 최신 뉴스 수집 용도가 아니다.

향후 추천 기업 및 인기 테마 기능에서 다음과 같이 활용할 수 있다.

```text
기업명 / 테마 검색량
↓
최근 1~2주 검색 관심도 변화
↓
인기 테마 판단 보조
```

데이터랩은 뉴스 API를 대체하지 않는다.

---

## ⑤ 외부 뉴스 API — MVP 이후

MVP에서는 사용하지 않는다.

MVP 이후 실제 이용 가능한 뉴스 데이터 공급자를 선정하여 연동한다.

필요 데이터:

* 기업 관련 최신 뉴스
* 뉴스 제목
* 뉴스 URL
* 발행일
* 뉴스 본문 또는 요약 가능한 콘텐츠

뉴스 API 선정 시 다음을 확인한다.

* 한국 기업 및 주식 뉴스 검색 가능 여부
* 무료 또는 저비용 사용 가능 여부
* API 호출 제한
* 상업적 서비스 이용 가능 여부
* 데이터 저장 및 재사용 조건

---

## ⑥ 시장 데이터 API — MVP 이후

추천 기업 기능을 구현하기 위해 시장 데이터를 추가한다.

필요 데이터:

* 종목별 일별 거래량
* 종목별 거래대금
* 거래량 변화율
* 거래대금 변화율

공식 시장 데이터 소스로 KRX Open API 등을 우선 검토한다.

실제 도입 전 다음을 확인한다.

* 필요한 거래량·거래대금 API 제공 여부
* API 사용 승인 절차
* 호출 제한
* 상용 서비스 이용 가능 여부
* 데이터 재제공 및 저장 조건

# 11. 기술적 제약 및 구현 원칙

## ① 외부 API 호출 제한

DART API의 Rate Limit과 호출량을 고려한다.

대응:

* Redis / Memory Cache
* API 호출 최소화
* TTL 설정
* Retry
* Rate Limit 관리

MVP 이후 뉴스 API 및 시장 데이터 API를 추가할 경우 각 API의 호출 제한을 별도로 관리한다.

---

## ② DART 기업 식별자 관리

사용자의 종목코드와 DART `corp_code`가 다르므로 Company Master를 구축한다.

```text
company_id
├── company_name
├── stock_code
├── corp_code
└── industry
```

모든 기업 분석은 `company_id`를 중심으로 연결한다.

---

## ③ 검색과 추천의 분석 로직 통합

사용자가 기업을 검색하여 들어오든 추천 기업을 클릭하여 들어오든 동일한 `company_id`를 사용한다.

```text
검색
  └─→ company_id ─┐
                   ├─→ Company Analysis
추천
  └─→ company_id ─┘
```

기업 분석 페이지와 분석 API를 중복 구현하지 않는다.

---

## ④ 업종별 기준의 불확실성

업종별 지표 특성은 절대적인 기준이 아니다.

따라서 다음과 같은 단정적 표현을 지양한다.

> "부채비율 100% 이상이면 위험하다."

대신:

> "일반적인 기준에서는 높은 편이며, 해당 업종의 특성을 고려할 때 상대적으로 높은 수준으로 볼 수 있습니다. 다만 최근 3년간 부채비율은 감소하고 있습니다."

와 같이 **일반 기준 + 업종 특성 + 과거 추세**를 함께 고려한다.

---

## ⑤ AI 분석 신뢰성

AI 분석은 참고용 정보이며 투자 판단을 직접 대신하지 않는다.

가능한 경우 분석 결과에 다음을 제공한다.

* 데이터 기준일
* 분석 근거
* 원본 데이터

AI가 제공하는 해석과 실제 DART 데이터를 명확하게 구분한다.

---

## ⑥ API Key 보안

외부 API 인증정보는 프론트엔드에 노출하지 않는다.

모든 외부 API 호출은 백엔드에서 수행한다.

```text
Frontend
    ↓
FastAPI Backend
    ├── DART API
    └── OpenAI API
```

API Key는 `.env` 환경변수로 관리한다.

예:

```env
DART_API_KEY=
OPENAI_API_KEY=
```

`.env` 파일은 Git 저장소에 커밋하지 않는다.

# 12. 성공 기준

## MVP

### 기업 분석 완료 시간

기업 검색 후 핵심 분석 정보를 확인하는 데 걸리는 시간.

**목표: 3분 이내**

### 분석 완료율

기업 검색 사용자 중 재무 분석까지 확인하는 비율.

**목표: 60% 이상**

### 재방문율

분석 경험 후 다시 서비스를 이용하는 사용자 비율.

**목표: 초기 사용자 기준 주간 재방문율 30% 이상**

### 사용자 가치 검증

> "이 서비스를 사용하면 기업 분석 시간이 줄어든다고 느끼십니까?"

**목표: 긍정 응답 70% 이상**

### API 안정성

외부 API 장애 발생 시에도 캐시 데이터를 활용하여 핵심 재무 분석 화면을 유지한다.

---

## MVP 이후

### 추천 기업 이용률

홈 화면 방문 사용자 중 추천 기업을 클릭하는 비율을 측정한다.

### 추천 기업 분석 전환율

추천 기업을 클릭한 사용자 중 기업 분석 Dashboard를 실제로 확인하는 비율을 측정한다.

### 즐겨찾기 이용률

기업 분석 사용자 중 하나 이상의 기업을 즐겨찾기에 추가하는 비율을 측정한다.

추천 기업 및 즐겨찾기 기능이 **사용자의 분석 시작과 재방문을 실제로 증가시키는지** 검증한다.

# 13. 핵심 제품 가설

FinancePilot AI의 핵심 가설은 다음과 같다.

> **"개인 투자자는 기업을 분석하기 위해 복잡한 재무 데이터를 직접 찾아 해석하는 데 많은 시간을 사용한다. DART의 재무 데이터를 하나의 화면에 통합하고, 업종 특성과 과거 추세를 고려하여 AI가 이해하기 쉽게 해석해 준다면 기업 분석 시간을 줄이고 투자 판단에 필요한 핵심 정보를 더 빠르게 파악할 수 있을 것이다."**

MVP 이후에는 다음 가설을 추가한다.

> **"기업을 분석하고 싶어도 어떤 기업을 봐야 할지 모르는 사용자가 많다. 최근 시장의 관심이 높아진 테마와 관련 종목을 제공하면 사용자가 분석할 기업을 쉽게 발견하고, 기업 분석 서비스의 사용 빈도와 재방문율을 높일 수 있을 것이다."**

최종 사용자 경험:

```text
[홈]

기업 검색
또는
최근 인기 테마 / 추천 기업
        │
        ├──→ 추천 기업 선택
        │
        └──→ 기업 검색
                ↓
            Company ID
                ↓
        기업 분석 Dashboard
                ↓
          DART 재무 데이터
                ↓
        업종 특성 + 과거 추세
                ↓
          AI 종합 재무 분석
                ↓
      강점 / 위험요인 / 성장성
                ↓
          투자 체크포인트
                ↓
            ⭐ 즐겨찾기
```

### MVP 최종 목표

> **"기업명 하나만 입력하면, 3분 안에 그 기업의 재무 상태와 성장성을 이해할 수 있다."**

### MVP 이후 최종 목표

> **"분석할 기업을 모르는 사용자도 최근 시장의 관심 테마에서 기업을 발견하고, 바로 FinancePilot의 AI 기업 분석을 이용할 수 있다."**
